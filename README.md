# Metadata inspector

Drop a file, see every piece of metadata it carries, and download a copy with it removed.

Everything runs client-side. No file ever leaves your device, there is no backend and no upload. That matters more here than on the other tools: the metadata is the sensitive part.

## What it handles

| Format | Reads | Removes |
|---|---|---|
| JPEG | EXIF, GPS, IPTC, XMP, Photoshop, maker notes, comments | every APPn segment except JFIF, the ICC profile and the Adobe colour marker; COM; anything after the end-of-image marker (motion-photo video, depth maps) |
| PNG | text chunks, eXIf, XMP | every chunk not on an allowlist of image-structure chunks |
| WebP | EXIF, XMP | the EXIF and XMP chunks, with the VP8X flags cleared |
| PDF | Info dictionary, document XMP | both, via pdf-lib rewriting the file |
| docx, xlsx, pptx, odt, ods, odp | core, app and custom properties, `meta.xml` | property parts emptied; comment and tracked-change author names blanked |
| HEIC/AVIF, TIFF, GIF | EXIF, XMP | not supported: the button is hidden and the card says so |

Not handled: audio and video (ID3, MP4 atoms), per-object XMP inside PDFs (embedded images, form fields), the text of Office comments and tracked changes, PDF encryption (the file is refused with the error).

After stripping, the cleaned bytes are read again and the card reports how many fields remain. It should always say none.

## Stack

Plain HTML, CSS and JavaScript. No build step. CSS, the background canvas, `pdf-lib` and `jszip` are copied from `pdf.harrys.monster`; `exifreader` (v4.44.1, UMD build) is vendored for reading image metadata. Stripping is hand-written per container in `js/formats.js` because no vendored library does it.

## Developing

```bash
python3 -m http.server   # then open http://localhost:8000
npm test                 # node --test over js/formats.js
```

Image fixtures under `test/fixtures/` are generated by `make.py` (needs Pillow).

## Deployment

Cloudflare Worker with static assets, custom domain declared in `wrangler.jsonc`. `npx wrangler deploy`; details in `docs/DEPLOY.md`.
